06FAQ

Questions, answered.

More on plans and data in the pricing and security pages.

Pricing →Security →
Does a cloud model ever see client documents?

Only if you allow it. Folders marked local-only are read by a model on your laptop and never sent anywhere. For other folders, each task shows which model it will use before it runs.

How do I know the numbers are right?

Sums are calculated in code rather than written by a model, and every figure links to the file and page it came from, so you can check any number in one click.

Does it work with my accounting software?

Titan reads exports such as CSV and Excel, and can replay tasks you record once in a web portal. It asks before it enters or changes anything.
